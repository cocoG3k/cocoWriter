# cocoWriter development

`ios/` is the shared application source. Configured Xcode projects generated by
`tools/configure-variant.py` reference these files directly; do not create a second
copy of the Swift sources or edit a generated project by hand.

Read `AGENTS.local.md` when it exists. It describes the user's active local variant
and installation workflow. Local profiles, signing teams, device backups, IPA files
and account-specific settings belong in `.local/` and must not be committed or
included in source releases.

For an existing installation, preserve its app and extension Bundle Identifiers,
App Group, storage directory, Keychain service and publishing destination. Do not
erase or reinstall an app to perform an upgrade. Do not replace an AltStore upgrade
with an Xcode installation on a physical device.

Regenerate a variant from its profile after changing project settings or resources.
Swift edits apply immediately because the sources are shared. For changes to storage,
identity or article compatibility, run `tools/test_app_variants.py`,
`tools/test_build_profiles.py`, `tools/test-ios.py` and `tools/check-project.py`.
